Methodology PDF brief

Synthetic weather. No real weather data was available when these numbers were built. Every figure on this page tests the pipeline only and is not an estimate of Cirata's output.

What this is: Cirata publishes only annual and cumulative output, so this is a forecast from a physics model, checked against sparse reports. It is not a calibrated model and it is not live data.
